============================================
  ECLIPSE V6: MASTER TALENT TREE & BUILDCRAFT DIRECTIVE
  Momentum Labs | Hermes | Malene | Forge | UE5.8
============================================

MISSION: Create a deeply interconnected, strategically meaningful
talent and character-build system for Eclipse: Realms of the Fractured.

Draw inspiration from MMORPG buildcraft depth but create original
systems, mechanics, naming, visuals and gameplay identities unique
to Eclipse. V6 is the authoritative design source.

GOAL: Every class, specialization, affinity and dual-affinity
combination must support multiple viable playstyles through
meaningful mechanical choices. A build must feel like a deliberately
engineered combat strategy, not a random collection of passive bonuses.

TALENT LAYERS:
A. Class Foundation — identity, survival, movement, utility, resources
B. Specialization Tree — combat fantasy, role, rotation, keystones
C. Affinity Tree — elemental mechanics, synergies, interactions
D. Dual-Affinity Convergence — cross-tree synergy, hybrid abilities, capstones
E. Game Mode Adaptation — Solo, Dungeon, Raid, Arena, Battleground

NODE TYPES: Active unlocks, passive improvements, ability transforms,
proc/reaction, resource gen/spend, cooldown interactions, conditional
damage/healing, defensive/mobility, CC/utility, cross-ability synergy,
cross-affinity convergence, choice nodes, keystones, capstones.

RULE: No generic "+X% damage" filler. Every talent must produce an
identifiable gameplay benefit and justify its tree position.

SYNERGY GRAPH: Directed dependency graph per build family. Classify:
required prerequisite, direct synergy, optional complementary,
conditional game-mode, mutually exclusive, potential anti-synergy.

FIRST DELIVERABLE: One complete playable build family:
- Verified V6 class
- Verified specialization
- Verified dual-affinity pairing
- 3+ mechanically distinct build variants
- Complete talent descriptions
- Functional ability interactions
- Playable rotations
- UI + save/load
- Automated validation
- Real in-engine combat evidence

8-POINT QUALITY GATE:
1. Every build has clear identity + central mechanic
2. Prerequisites and point budgets valid
3. Cross-affinity talents reward both affinities
4. 3+ meaningfully different builds work per specialization
5. Every major build has functional rotation/priority
6. PvP tuning preserves counterplay
7. AI companions can execute talent builds
8. All talents function, display, and save reliably

FINAL PRINCIPLE: Every talent point must meaningfully strengthen,
modify or diversify a coherent playstyle. A talent combination should
change what you cast, when you cast it, how you manage resources,
how you move, how you survive, and how you coordinate with companions.
