============================================
  ECLIPSE V6: EIGHT HIGH-IMPACT DIRECTIVES
  Production Intelligence System
============================================

1. AUTONOMOUS PRODUCTION INTELLIGENCE
   - Dependency-aware scheduling
   - Integration discipline (no shared file overwrites)
   - Evidence-backed production dashboard
   - Classify: design-only → code authored → compiled → 
     editor-tested → gameplay-tested → packaged → production-ready
   - Never confuse code generation with functional completion

2. AAA-GAME FEEL DIRECTOR
   - Movement: accel/decel, turning, strafing, dodge, jump
   - Combat: hit-stop, camera impulse, recoil, stagger, weight
   - Responsiveness: input buffering, combo windows, GCD
   - Visual/audio sync: weapon trails, impact timing, telegraphs
   - Do not increase spectacle at expense of readability

3. ART-TO-ENGINE PRODUCTION PIPELINE
   - Character: concept → refs → mesh → retopo → UV → textures →
     rig → animation → materials → import → test → profile
   - Environment: reference → blockout → composition → modular →
     materials → lighting → set dressing → effects → optimize
   - Aetherborn: preserve muscular build, fracture markings,
     energy wings, skin integration
   - No concept art approved as game-ready without full pipeline

4. REACTIVE WORLD & SPELL INTERACTION
   - Surface reactions: stone, metal, wood, water, ice, 
     vegetation, cloth, earth, fracture energy
   - Spells interact with environment physically
   - Volumetric lighting from spell illumination
   - Destructible elements, persistent scorch marks
   - Material-driven reaction system (data-driven)

5. ENEMY & BOSS INTELLIGENCE
   - Enemies adapt to player build, coordinate, use tactics
   - Boss phases with readable telegraphs and counterplay
   - AI uses same combat framework as player

6. PROCEDURAL CONTENT WITH HUMAN-QUALITY STANDARDS
   - Accelerate production without repetitive environments
   - Authored composition + procedural variation

7. AUTOMATED GAMEPLAY & BALANCE LABORATORY
   - Test builds, spells, progression, boss encounters
   - Deterministic simulation, reproducible results

8. CONTINUOUS PLAYABLE BUILDS
   - Always produce something you can actually play
   - Every milestone = packaged Windows build
