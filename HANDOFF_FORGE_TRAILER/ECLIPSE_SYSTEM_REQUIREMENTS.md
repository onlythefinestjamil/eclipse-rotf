# ECLIPSE: REALMS OF THE FRACTURED
## Target System Requirements

### PC

| | Minimum | Recommended |
|---|---|---|
| **OS** | Windows 10 64-bit | Windows 11 64-bit |
| **CPU** | Intel i7-8700 / AMD Ryzen 5 3600 | Intel i7-12700K / AMD Ryzen 7 5800X |
| **RAM** | 16 GB | 32 GB |
| **GPU** | RTX 2060 6GB / RX 5700 8GB | RTX 3070 8GB / RX 6800 16GB |
| **VRAM** | 6 GB | 8-16 GB |
| **Storage** | 100 GB SSD | 200 GB NVMe SSD |
| **DirectX** | 12 | 12 |
| **Resolution** | 1080p | 4K |

### Consoles

| Console | Support | Notes |
|---|---|---|
| **PS5** | Full | 16GB GDDR6, Zen 2 - Lumen + Nanite + Path Tracing |
| **Xbox Series X** | Full | 16GB GDDR6, Zen 2 - same as PS5 |
| **Xbox Series S** | Reduced | 10GB GDDR6 - Lumen settings reduced, lower resolution |

### Technical Justification

- UE5.8 with Lumen + Nanite requires at least 6GB GPU for 1080p
- 32 GB RAM recommended for World Partition + high-res textures
- SSD required - World Partition streaming needs fast storage
- RX 6800 16GB (dev machine) is in the recommended tier

### Dev Machine Specs

- AMD Ryzen 9 7900X (12-core/24-thread)
- 128 GB DDR5 RAM
- AMD Radeon RX 6800 (16GB VRAM)
- Windows 11 Pro
- 6 drives (~9.9TB), K: 4TB SSD for development
- UE5.8 installed at C:/Program Files/Epic Games/UE_5.8/
